Biomedical Data Analysis with Python#

Lab module · 2 hours · Year 2, October 2026, Introduction to Biomedical Engineering

University of Deusto

By: Cyrille YetuYetu Kesiku | Cordonator : Prof Begonya Garcia-Zapirain

In this lab you analyse a real 26-minute, 14-channel EEG recording acquired with an Emotiv EPOC X headset. You will move from the physics of the signal to a complete analysis in Python: data dictionary, time axis, quality control, descriptive and inferential statistics, Fourier analysis, filtering, band power and a mini-project. Every figure and number in these pages is produced by the code shown.

What you will be able to do

  • Explain what an EEG measures and describe every one of the 76 variables of the CSV file.
  • Check the sampling rate, completeness and quality of a biomedical recording.
  • Apply second-year statistics to signals, and know when their assumptions break.
  • Compute and interpret spectra, filters, band power, spectrograms and a PCA.
  • Write a short, honest analysis report with sample sizes, effect sizes and limitations.

The recording at a glance#

File SE_EPOCX_dataset.csv: 199,705 rows × 76 columns, 26.0 minutes at 128 Hz, 14 EEG channels (AF3, F7, F3, FC5, T7, P7, O1, O2, P8, T8, FC6, F4, F8, AF4), plus contact quality, signal quality and a motion unit. Recorded on 4 March 2024. No event markers: the file does not tell us what the subject was doing.

Setup#

Environment

Python 3.9 or later with numpy (2.0+ for np.trapezoid; on older versions use np.trapz), pandas, scipy and matplotlib.

pip install numpy pandas scipy matplotlib

All code of the lab is collected in lab_code.py (also on the top bar, .py), with cells separated by # %%: open it in VS Code or Spyder, or paste it in Jupyter. Put the CSV in the same folder.
